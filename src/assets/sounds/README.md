# 音源
同梱の8種類のWAVは本プロジェクト用の合成音です。外部通信・外部素材は使用していません。
hover / click / countdown / start / stop / finish / rank-in / new-record の名前で wav, mp3, ogg を差し替え、再ビルドしてください。同じ名前の拡張子違いは一つだけ配置してください。
bgm.wav (またはmp3/ogg) を追加すると待機ランキング画面でのみループします。未配置ならBGM ONでも無音です。
音源の削除・ロード失敗は計測を阻害しません。
kamatamago_C00003_heaven-and-hell.mp3 はレースBGMです。スタートボタン（Enterキー）で再生を始め、カウントダウン〜計測中はループし、ストップで停止します。管理画面の「レースBGM」でON/OFF、「BGM音量」で音量を調整できます。
